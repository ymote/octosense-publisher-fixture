# OctoSense publishing acceptance fixture

This small local-notes app exercises GitHub-based developer publication without a developer-managed signing key. The GitHub release is a candidate for review; it is not App Hub admission.

The source bundle is editable. The release pack holds the sealed manifest and its GitHub attestation. Never restamp the sealed pack.

Versions 0.1.2 and later declare macOS and Android for isolated host acceptance. A release does not claim that device acceptance has passed; the test receipt records actual results. No App Hub submission or production admission is requested for this fixture.
